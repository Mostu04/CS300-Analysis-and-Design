# CS300-Analysis-and-Design
## CS 300 Portfolio Reflection

### What was the problem you were solving in the projects for this course?

The projects focused on developing a program that would help academic advisors access course information for students at ABC University. In Project One, I evaluated different data structures to determine which would be the most effective for storing and retrieving course information. In Project Two, I used that analysis to develop a working C++ program that loads course data from a file, displays courses in alphanumeric order, and allows users to search for individual courses and their prerequisites. 

### How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by comparing vectors, hash tables, and binary search trees to understand how each would handle storing, searching, and organizing course information. Looking at their run-time efficiency and memory requirements helped me see that choosing a data structure involves more than just getting a program to work. I selected a hash table because it provided efficient course lookups. Since hash tables don't automatically store information in order, I also used sorting to display the courses alphabetically.

### How did you overcome any roadblocks you encountered while going through the activities or project?

One of the challenges I encountered was translating pseudocode into working C++ code. I understood the general logic, but making sure the different functions worked together required additional attention. I also ran into a few errors while compiling and testing my program, including a spelling mistake that prevented the code from compiling. I worked through these issues by reviewing the error messages, checking the relevant sections of code, and testing each menu option individually. Breaking the work into smaller steps helped me identify problems and understand how to correct them.

### How has your work on this project expanded your approach to designing software and developing programs?

These projects helped me understand the important of planning a program before starting to write code. Previously, I thought the more important focus was to get the program to produce the expected results, but this course encouraged me to think about how the data would be organized and accessed. I also learned that a program can have more than one solution, and choosing the right approach depends on what the program needs to accomplish.

### How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

This course has helped me become more intentional about how I organize and document my code. In Project Two, I separated tasks into functions for loading course data, displaying the course list, and searching for individual courses. This made the program easier to follow and allowed me to test each function separately. I also became more aware of the importance of meaningful variable names, comments, and input validation. Moving forward, I want to continue writing code that not only works correctly but is also easy to understand, troubleshoot, and modify when requirments change.
